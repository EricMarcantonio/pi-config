# pi-config

My [pi](https://github.com/earendil-works/pi-coding-agent) coding-agent config: custom provider/models (Ollama cloud), pricing + context windows, subagents, prompts, and a todo extension.

## What's in here

| path | what |
|---|---|
| `settings.json` | default model/provider, theme, installed packages |
| `models.json` | custom `ollama` provider: 20 cloud models with `cost` (USD/1M tokens) and `contextWindow` |
| `agents/` | subagent definitions (`scout`, `planner`, `worker`, `reviewer`) |
| `prompts/` | prompt templates (`/implement`, `/scout-and-plan`, `/implement-and-review`) |
| `extensions/` | `todo.ts`, `subagent/`, `wordy-footer.ts` |
| `.gitignore` | excludes caches, sessions, secrets |

Not included (regenerated by pi): `npm/`, `git/`, `bin/`, `auth.json`, `models-store.json`, `sessions/`.

## Install

The whole config dir is overridable with `PI_CODING_AGENT_DIR` (default `~/.pi/agent`).

### Option A — copy into existing config

```bash
cp settings.json models.json ~/.pi/agent/
cp -r agents prompts extensions ~/.pi/agent/
```

### Option B — use this repo as your config dir

```bash
git clone https://github.com/EricMarcantonio/pi-config ~/pi-config
export PI_CODING_AGENT_DIR=~/pi-config   # add to ~/.zshrc / ~/.bashrc
```

Then install the packages listed in `settings.json`:

```bash
pi install npm:@ollama/pi-web-search
pi install npm:pi-caveman
pi install npm:pi-mcp-extension
pi install git:github.com/obra/superpowers
```

## Notes

- **Ollama models**: `models.json` points at `http://127.0.0.1:11434/v1` with `apiKey: "ollama"`. Change `baseUrl` if your Ollama isn't local. All model ids use the `:cloud` suffix.
- **Costs** are USD per 1M tokens, off-peak rates only (pi has no time-of-day pricing; Ollama peak, Mon–Fri 12–18 UTC, is ~2×).
- **Context windows** come from `ollama show <model>`.
- **No secrets** are stored here (`apiKey` is the literal `"ollama"`).
- **Wordy footer**: `extensions/wordy-footer.ts` replaces pi's symbol footer (`↑ ↓ R W CH`) with words (`input`, `output`, `cache-read`, `cache-hit`, `cost`, `context`). Toggle at runtime with `/footer-words`. Delete the file to restore the default footer.
